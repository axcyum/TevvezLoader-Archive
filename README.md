# Release info
I have compiled a collection of plugins compatible with the Tevvez loader. I have ensured that the versions provided are the most recent .<br>
I have also included the file used to hook into VRC (essentially a DLL, though it contains custom logic, so it is not strictly a standard DLL). The loader allows for the simultaneous use of this Tevvez component alongside regular DLLs (such as Unity Explorer).
